# EECS 581 HW 1
## Assignment Description
The assignment contains an extract_ipv4.c file located within the src folder and an AI Disclosure document located in the docs folder.
## Initial Setup
1. Clone the repository
2. Open the repository folder in VS Code or any other IDE.
3. Open a terminal at the repository root.
## Running the Project 
Compile the project by running the following:
```bash
gcc extract_ipv4.c -o 581_hw1
```
To enter the sentinel loop run: 
```bash
./581_hw1
```
To run all test cases run:
```bash
./581_hw1 --test
```
